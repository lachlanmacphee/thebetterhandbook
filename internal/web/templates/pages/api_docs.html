API Documentation

Use the API endpoints below to fetch university and unit data as JSON.

GET /api/universities
GET /api/units

Universities Endpoint

GET /api/universities
Optional query params: name, sortBy (name or unitCount), page, and pageSize (10, 20, or 50).

Units Endpoint

GET /api/units
Optional query params: university (a university's slug, e.g. monash-university), code, name, faculty, level, creditPoints, campus, semester, sortBy (code, name, rating or reviews), page, and pageSize (12, 24, or 36). faculty, campus and semester take IDs from previous responses.
